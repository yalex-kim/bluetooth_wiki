## 2 Changes to Source Specifications

[The following text replaces existing conformance text listed in Table 2.1 in the Impacted Section column for each specification listed. If a specification currently has no Conformance section, this text will be inserted as a new section.]

This specification may provide options for design flexibility, because, for example, some products do not implement every portion of the specification. For each implementation option that is supported, it shall be supported as specified.
