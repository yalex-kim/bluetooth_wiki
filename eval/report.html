Gaps & Content Issues Found by Independent Evaluation
Q028 · SIGNIFICANT GAP Supervision timeout minimum: wiki formula gives 2010 ms vs spec-recommended 12,000 ms
The independent agent correctly computed Effective_Interval=2000ms but stated minimum supervision timeout = 2010ms using the strict spec formula (> 2×CI×SF×(Max_Latency+1)). The reference answer expects 12,000ms based on the ≥6×Effective_Interval design guideline. The wiki's ble-parameters.md documents the strict minimum but not the 6× practical minimum, causing the gap.
Update ble-parameters.md and connection-management.md to state: recommended minimum = 6 × Effective_Interval = 12,000ms for SF=10, CI=100ms, CN=1 example.
Q013 / Q017 · MEASUREMENT AMBIGUITY Extended advertising payload: wiki reports chain total (1650 bytes), not single PDU max (254 bytes)
The wiki's advertising.md states up to 1650 bytes across the AUX_ADV_IND + AUX_CHAIN_IND chain; the reference key_fact uses 254 bytes (max payload of a single AUX_ADV_IND PDU). Both are correct measurements of different things; the wiki should clarify both.
Add a note to advertising.md distinguishing single-PDU max (254 bytes) from total chain capacity (1650 bytes).
Q014 · ATTRIBUTION ERROR Advertising Coding Selection attributed to 5.4 instead of 5.3
The wiki lists Advertising Coding Selection as a new 5.4 feature; the reference key_fact and the diff-5.2-to-5.3 page attribute it to 5.3. Since 5.3 was withdrawn and superseded by 5.4, the feature effectively shipped in 5.4, but the original introduction was in 5.3. The wiki should be consistent about version attribution.
Clarify in diff-5.2-to-5.3.md and core-spec-5.4.md that Advertising Coding Selection was introduced in 5.3 and carried over to 5.4.
Q023 · SEQUENCE ORDERING BIS HCI sequence: extended advertising enable placed after periodic advertising enable
The wiki's hci-sequences.md §7a enables periodic advertising (step 5) before extended advertising (step 6). Per spec, periodic advertising can only be enabled on an active extended advertising set — extended must be enabled first. Reference sequence has extended advertising enabled at step 3, before setting up periodic.
Swap steps in hci-sequences.md §7a: HCI_LE_Set_Extended_Advertising_Enable must come before HCI_LE_Set_Periodic_Advertising_Enable.
Q024 / Q025 · MINOR NAMING Subrating command names and ECDH model differ slightly from reference
Wiki uses HCI_LE_Set_Default_Subrate / HCI_LE_Subrate_Request; reference uses HCI_LE_Set_Connection_Subrate_Default / HCI_LE_Connection_Subrate_Request (same opcodes). For LESC (Q025), wiki describes controller-offloaded DHKey via HCI_LE_Generate_DHKey; reference key_fact describes host-side ECDH (older model). Both are spec-accurate for different BLE generations.
Minor: Verify command names match the latest Core 6.2 Vol 4 Part E table. For Q025, note that HCI_LE_Generate_DHKey was added to allow controller offload in 5.2+.
